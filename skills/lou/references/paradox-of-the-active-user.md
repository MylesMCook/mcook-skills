# Paradox of the Active User

Source concept: https://lawsofux.com/paradox-of-the-active-user/

## When to load

Load this reference when onboarding, tooltips, help, empty states, complex tools, settings, documentation, first-run experiences, or novice use.

## Lens

Users often start doing the task immediately instead of reading manuals or setup instructions, even when learning first would save time.

## Look for in the design

- guidance only available before the user starts
- manual-like text that users must read to proceed
- novices forced into errors before contextual help appears

## Critique moves

- Move guidance into the flow at the moment of use.
- Let users safely start, then teach through contextual prompts, examples, or progressive disclosure.
- Support recovery from exploratory mistakes.

## Watch-out

Do not replace the whole product with onboarding; active users still want to make progress.
