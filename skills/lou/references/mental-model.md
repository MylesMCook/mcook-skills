# Mental Model

Source concept: https://lawsofux.com/mental-model/

## When to load

Load this reference when conceptual models, terminology, IA, workflows, account structures, permissions, search, ecommerce, or unfamiliar domains.

## Lens

People use compressed internal models of how a system works to predict what will happen next.

## Look for in the design

- system concepts that do not match how users describe the task
- actions whose outcomes are hard to predict
- information architecture organized around internal teams instead of user goals

## Critique moves

- Map UI language and structure to the user's model, not the backend model.
- Make state changes and consequences visible before users commit.
- Use research assumptions explicitly when the user's mental model is uncertain.

## Watch-out

Do not assume the reviewer's mental model is the user's mental model; state the persona or evidence needed.
