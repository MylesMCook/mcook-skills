# Forms

Use these only when context is too thin to proceed confidently.

## Quick Taste Pass Intake

- Surface type:
- Audience:
- Main action or task:
- Brand tone desired:
- Existing problems the user feels:
- Constraints (accessibility, device, platform, deadline):
- Artifact available? (screenshot, code, URL, mockup):
- What must not change?

## Deep Redesign Intake

- What is this surface for?
- What should the user notice first?
- What should the user feel?
- Where does the current design feel generic, weak, loud, messy, cheap, or unclear?
- Is the product/system already branded?
- Are there implementation constraints or legacy components?
- Which environments matter most? (desktop, mobile, print, kiosk, deck, etc.)
- Is this a critique, a redesign spec, or an implementation pass?

If most of this is inferable from the user’s request or artifact, do not ask. Proceed and state assumptions.
