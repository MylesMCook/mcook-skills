# Environments

Use the same laws differently depending on the surface.

## Web apps / SaaS products

Default stance:
Calm, exact, trustworthy, fast to scan.

Primary risks:
- component soup
- overuse of soft cards and low-contrast neutrals
- fake premium through blur, gradients, and chrome
- weak empty/error/loading states

Taste moves:
- one clear primary action per region
- stable navigation
- disciplined spacing scale
- strong table and form typography
- color reserved for action, state, anomaly, and emphasis
- remove decorative surfaces that do not create grouping

## Mobile apps

Default stance:
Primary action and context must survive compression.

Primary risks:
- collapsed desktop hierarchy
- oversized chrome
- over-dense menus
- tiny unreadable secondary text
- gesture magic with no explanation

Taste moves:
- decide the one thing the screen is for
- simplify top bars and bottom bars
- group by task, not by database model
- use large type where it matters, not everywhere
- let motion explain transitions

## Dashboards / data-heavy tools

Default stance:
Signal over spectacle.

Primary risks:
- everything highlighted
- too many charts
- decorative color palettes
- weak anomaly detection
- unreadable tables and legends

Taste moves:
- make comparison easy
- use neutrals for baseline, accent only for change/anomaly
- reduce chart count and increase interpretability
- direct-label where possible
- make filters feel orderly and secondary to insights
- use spacing and rules to improve parse speed

## Design systems / component libraries

Default stance:
One worldview, many expressions.

Primary risks:
- visual inconsistency between primitives
- state logic that varies from component to component
- token explosion
- excessive component branching

Taste moves:
- unify radii, borders, shadows, typography, densities, and motion
- define primary/secondary/tertiary emphasis rules
- make states feel related
- design tables, forms, and nav with as much care as hero banners
- keep the system memorable through a few strong signatures

## Marketing pages / brand sites

Default stance:
Memorable first impression, but not at the expense of legibility.

Primary risks:
- cinematic hero with no story
- too many accents
- weak message hierarchy
- brand gestures that vanish below the fold

Taste moves:
- one conceptual hook per section
- strong headline rhythm
- decisive image treatment
- fewer, bolder sections
- let typography and scale do more than decoration
- make proof blocks and CTAs visually inevitable

## Ecommerce

Default stance:
Reduce doubt, increase desire, accelerate choice.

Primary risks:
- product page clutter
- timid product imagery
- weak hierarchy between price, variant, details, shipping, and action
- promotional noise overwhelming decision-making

Taste moves:
- make product media excellent
- create a clear buy path
- subordinate promotional badges unless critical
- use comparison and specification tables elegantly
- turn reviews and proof into readable editorial support, not visual junk

## Forms / checkout / onboarding

Default stance:
Serious, patient, friction-aware.

Primary risks:
- too many competing instructions
- inconsistent field groupings
- error states that feel punitive
- visual heaviness

Taste moves:
- group semantically
- reduce unnecessary borders and helper text
- make labels and examples calm and consistent
- highlight only the current problem
- use progress and reassurance sparingly but clearly

## Editorial / blogs / newsletters / long-form reading

Default stance:
Reading is the product.

Primary risks:
- treating articles like generic web blocks
- weak relation between headline, stand-first, imagery, and body
- long line lengths and lazy vertical spacing
- no compositional drama

Taste moves:
- design the entry points
- let image and type interact meaningfully
- use subheads, pull quotes, captions, and margin logic as part of the experience
- create a world, not just a flow of content blocks

## Slides / decks / presentations

Default stance:
A sequence of emphases, not a pile of pages.

Primary risks:
- each slide designed independently
- no rhythm across the sequence
- tiny type
- every slide screaming equally

Taste moves:
- give the deck a typographic and spacing system
- alternate dense and spare slides
- let one message dominate per slide
- use repetition for trust and strategic deviations for impact

## Documents / PDFs / reports

Default stance:
Authority through structure.

Primary risks:
- default software styling
- weak tables and charts
- too many heading levels with no visible logic
- cover page stronger than internals

Taste moves:
- create a strong grid and style sheet
- make data displays sober and clear
- ensure running heads, captions, notes, appendices, and contents pages feel as designed as the title page

## Print, packaging, signage, environmental graphics

Default stance:
Clarity at distance, texture up close.

Primary risks:
- digital assumptions carried into physical scale
- poor contrast
- too many messages competing in one field
- brand signal not surviving format changes

Taste moves:
- test at real size
- design for three distances: far, near, hand-held
- use form, interval, and silhouette as much as text
- let the system persist across many surfaces
