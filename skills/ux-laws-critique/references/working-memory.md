# Working Memory

Source concept: https://lawsofux.com/working-memory/

## When to load

Load this reference when multi-screen flows, comparison tasks, instructions, forms, dashboards, checkout, settings, or places where users must remember prior information.

## Lens

Working memory temporarily holds and manipulates information for the current task, but it is limited and fades quickly.

## Look for in the design

- users forced to remember values from a previous screen
- instructions separated from the field or action they govern
- comparison or decision tasks without persistent context

## Critique moves

- Carry relevant information forward so users can recognize rather than recall.
- Keep instructions, constraints, and examples near the place they are used.
- Use summaries, breadcrumbs, visited states, and comparison tables to externalize memory.

## Watch-out

Do not overload the current screen with every past detail; persist only what supports the next decision.

Cognitive Load, Chunking, Miller's Law
