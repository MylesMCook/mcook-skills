# Cognitive Load

Source concept: https://lawsofux.com/cognitive-load/

## When to load

Load this reference when complex workflows, dense screens, unfamiliar terminology, multi-step tasks, dashboards, forms, configuration, or feature-heavy pages.

## Lens

Every interface asks users to spend mental resources; unnecessary processing makes tasks feel harder and causes missed details.

## Look for in the design

- users forced to parse many elements before finding the next action
- decorative or redundant elements that compete with task information
- copy, hierarchy, or layout that makes users infer system rules

## Critique moves

- Remove or defer information that does not help the current decision.
- Make the primary path explicit through hierarchy, copy, and progressive disclosure.
- Replace recall-heavy instructions with visible cues and inline guidance.

## Watch-out

Do not flatten all complexity; distinguish unavoidable task complexity from avoidable interface noise.

## Pairs well with

Working Memory, Chunking, Tesler's Law
