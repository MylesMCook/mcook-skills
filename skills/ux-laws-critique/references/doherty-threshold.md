# Doherty Threshold

Source concept: https://lawsofux.com/doherty-threshold/

## When to load

Load this reference when loading, saving, search, filtering, checkout, AI generation, transitions, progress indicators, or any delayed system response.

## Lens

Interaction feels productive when the system and user keep pace, with feedback fast enough that neither seems to wait on the other.

## Look for in the design

- actions with no immediate acknowledgement
- loading states that hide whether work is happening
- delays where perceived value or trust depends on feedback

## Critique moves

- Add immediate feedback for taps/clicks/submissions and clear pending states for longer operations.
- Use skeletons, optimistic UI, progress indicators, or staged status messages to improve perceived performance.
- Reserve intentional delay only for trust-building moments, not routine work.

## Watch-out

Do not treat animation as a substitute for actual speed; it should explain or soften waiting.

## Pairs well with

Flow, Goal-Gradient Effect, Parkinson's Law
