# Composition Patterns

Load this when making a shot list, choosing structure, or inventing the metaphor.

## Pick one structure type

Choose one. Mixing structures makes the image feel like a slide.

### Workflow machine

Use for input -> processing -> output, content pipelines, AI workflows, approval paths, automations.

How to draw: input pile on the left, Inkblot or a strange low-tech machine in the middle, output on the right, orange arrow as the main flow.

### System slice

Use for information sources, filters, databases, routing, agent loops, moderation, search, memory, dashboards.

How to draw: only 3-5 modules, with Inkblot operating the decisive module. Avoid full architecture maps.

### Before/after contrast

Use for chaos/order, manual/automated, scattered/collected, anxious/steady, stuck/running.

How to draw: left side messy, right side calmer, orange motion between them. Keep each side simple.

### Character state

Use for pain points, creator state, tool overload, uncertainty, awkward handoff, "almost working."

How to draw: 2-4 small states, each with one short label. Make Inkblot carry the state physically.

### Concept metaphor

Use for abstract claims, trust, quality, compounding, feedback loops, prioritization, alignment.

How to draw: one memorable low-tech object or machine with a little input and one visible result.

### Method stack

Use for frameworks, layers, operating systems, content systems, capability ladders.

How to draw: stacked boxes, shelves, bins, or workbench layers. Avoid formal pyramids.

### Map or route

Use for user journeys, onboarding, learning paths, idea-to-launch paths, content handoff paths.

How to draw: one curving route with a few stations. Inkblot pulls, repairs, or walks the route.

### Tiny comic strip

Use for failure-to-success, before/during/after, repeated attempts, or a small ironic sequence.

How to draw: 2-4 panels max, each panel one action. Do not turn it into a full comic page.

## Anchor extraction

Good anchors:

- A decision point.
- A bottleneck or dead end.
- A trust gap.
- A loop that improves over time.
- A hidden handoff.
- A before/after behavior change.
- A tradeoff.
- A system that turns messy input into useful output.
- A failure mode that needs a visual warning.

Weak anchors:

- Generic introduction.
- Pure vibe sentence.
- Paragraphs that already explain themselves.
- Lists with too many equal items.
- Anything that would require 8+ labels to understand.

## Original metaphor method

1. Turn the abstract concept into a physical action: jam, leak, sort, ferment, weigh, bridge, patch, fold, route, plug, stamp, untangle, shrink, stretch, collect.
2. Turn the system into a low-tech object: cardboard box, drawer, mailbox, scale, receipt, highway ramp, pegboard, laundromat cart, coffee mug, diner counter, ticket window, old machine, pipe, ladder, workbench, bin, turnstile.
3. Make Inkblot perform the action. The metaphor should fail without Inkblot’s effort.

Use only one or two objects. Too many props turns the image into a scavenger hunt.

## Repetition guard

Do not reuse old source-project compositions by default: conveyor breakpoints, content-machine lever, fish-cutting reuse, funnel-as-character, three-source wire pull, stamp toolbox, common-mistakes path, or trust bridge. Keep the spirit, invent the current metaphor.

When the article suggests an obvious metaphor, twist the physical action. Example: for "trust bridge," do not draw another bridge; draw Inkblot laying receipts like stepping stones across a gap.
