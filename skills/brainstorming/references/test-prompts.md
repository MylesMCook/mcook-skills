# Test Prompts

Use these to sanity-check the skill in a fresh chat. A good run should feel like a strong thinking partner in conversation: fast framing, sharp questions, concrete options, useful recommendations, and no forced workflow baggage.

## 1) Fuzzy start

"I want to do something with AI for my business, but I don't know what actually makes sense."

Expected behavior:

- Frame the likely problem
- Offer a few plausible directions
- Ask one sharp question
- Recommend a default instead of staying vague

## 2) General planning

"I want to start some kind of side project, but I need help thinking through what it should be."

Expected behavior:

- Treat this as a normal trigger
- Help define goals and constraints
- Offer concrete project directions
- Narrow instead of endlessly ideating

## 3) Too many possibilities

"I'm torn between making a course, building a small SaaS, or starting a niche newsletter."

Expected behavior:

- Compare on useful criteria
- Cut weak paths
- Recommend one direction

## 4) Scope control

"I want to build a creator platform with messaging, billing, analytics, discovery, and brand deals."

Expected behavior:

- Call out that the scope is too big as stated
- Break it into slices
- Brainstorm the first sensible slice

## 5) Product direction

"I want to add an AI feature to my app but I'm not sure what the right feature is."

Expected behavior:

- Stay conversational
- Offer 2-4 directions
- Ask one high-leverage question
- Recommend a likely best first move

## 6) Naming / positioning

"I need a better name for a premium analytics tier. Current ideas are Pro Insights, Signal, and Pulse."

Expected behavior:

- Identify the naming axis
- Rank or cluster the candidates
- Produce a small number of stronger alternatives

## 7) Pressure test

"I think we should make onboarding fully conversational with an AI assistant."

Expected behavior:

- Explore upside and downside
- Surface UX and reliability risks
- Recommend a path that fits likely constraints

## 8) Personal planning

"I kind of want to change careers, but I don't know whether I should go deeper into product, try consulting, or build something of my own."

Expected behavior:

- Handle it as brainstorming, not therapy or a rigid framework
- Compare the paths on practical criteria
- Help narrow toward a real next move

## 9) Existing project, still early

"We have a cluttered settings page in our app and I want ideas for simplifying it."

Expected behavior:

- Stay in brainstorming mode
- Not demand repo inspection immediately
- Explore simplification patterns and decision criteria first

## 10) Ready to wrap

"Okay, I think option B is the one. Can you summarize the direction clearly so I can sit with it?"

Expected behavior:

- Produce a clean summary
- Note assumptions and open questions
- Not force a spec or implementation plan
