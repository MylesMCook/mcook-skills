# Chunking

Source concept: https://lawsofux.com/chunking/

## When to load

Load this reference when dense content, forms, tables, dashboards, onboarding steps, long pages, summaries, specs, or repeated UI modules.

## Lens

People process information more easily when individual items are grouped into meaningful units.

## Look for in the design

- unbroken fields or text blocks
- sections that mix unrelated decisions
- tables/cards where relationships are visually hard to scan

## Critique moves

- Group related elements under clear headings and visual boundaries.
- Convert long linear content into scannable modules aligned to the user's task.
- Use chunking to expose relationships, not merely to decorate the page.

## Watch-out

Do not over-chunk into so many modules that the page feels fragmented.

## Pairs well with

Miller's Law, Cognitive Load, Working Memory
