# Signature Moments

Use this file when the user wants delight, differentiation, or a brand-defining detail.

## When to Invest

A signature moment is worth considering when the interaction is:

- frequent enough to be remembered
- emotionally meaningful
- already functional
- short enough to stay out of the way
- aligned with the product's voice

## When Not to Invest

Do not force a signature moment when the interaction is:

- rare and invisible
- already high-friction
- safety-critical or urgent
- likely to interrupt completion
- only "delightful" because it adds spectacle

## Signature-Moment Test

Ask:

1. Would users notice if it disappeared?
2. Does it strengthen the product's identity?
3. Does it preserve clarity and speed?
4. Could it still work with reduced motion?
5. Is it still good without sound?

If the answer to any of the last three is no, it is probably decoration, not craft.
